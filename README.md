# RPG Game Console V2.1

A console RPG game written in Python.

## Features

- Battle system
- Critical hit
- Dodge
- Inventory
- Equipment
- Loot system
- Healing items
- Save / Load game

## Requirements

- Python 3.14+
- Python-colorama>=0.4.6

# Installation

## Arch Linux

```bash
sudo pacman -S python-colorama
sudo pacman -S python-pygame
```

## Ubuntu/Debian

```bash
sudo apt install python3-colorama
sudo apt install python3-pygame
```

## Windows/macOS

```bash
python -m pip install colorama
python -m pip install pygame
```

## Run

```bash
python main.py
